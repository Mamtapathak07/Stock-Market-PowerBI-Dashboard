# Stock Market Power BI Dashboard

## Project Overview

This Power BI dashboard provides an interactive analysis of stock market data as of 18 August 2026.
It focuses on stock price performance, breakout analysis, series-wise distribution, and industry-wise stock performance.

## Dashboard Features

- Breakout % analysis by Series
- Industry-wise Total Price and Total Stock analysis
- Total % Change analysis
- Previous High vs Current Price analysis
- Price Difference analysis
- Breakout % analysis
- Average, Maximum, and Minimum LTP
- Interactive Series slicer
- Reset Slicer button
- Detailed industry-wise data table

## Key Metrics

- Total % Change
- Total Previous High
- Total Price
- Total Stock
- Price Difference
- Breakout %
- Avg LTP
- Max LTP
- Min LTP

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
